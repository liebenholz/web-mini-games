## 1. 개요

2명이 8×8 판에 번갈아 돌을 둔다. 상대 돌을 내 돌 사이에 끼우면 그 돌들이 내 색으로 뒤집힌다. 둘 곳이 없으면 넘기고, 둘 다 둘 곳이 없으면 끝나며 돌이 많은 쪽이 이긴다.

| 항목 | v1 결정 |
| --- | --- |
| 인원 | 2명 (빈자리는 봇) + 관전 |
| 판 | 8×8 칸 |
| 처음 배치 | 가운데 네 칸에 흑백 두 개씩 대각선으로 (D4 백, E4 흑, D5 흑, E5 백) |
| 선 | 항상 흑. 누가 흑을 할지는 방장이 정한다 (오목과 같은 옵션) |
| 둘 곳 없음 | 자동으로 넘긴다. 모두에게 알린다 |
| 턴 시간 초과 | 둘 수 있는 자리 중 하나를 서버가 대신 둔다. 2번 연속이면 봇이 대신 진행 (RV-12) |
| 게임 중 퇴장 | 봇이 이어서 둔다. 상대에게 알린다 (오목과 같다) |
| 무르기 | 없음 |
| 베팅 / 재화 | 없음 |

## 2. 규칙

| ID | 규칙 | 상세 |
| --- | --- | --- |
| RV-01 | 판과 좌표 | 8×8. 열 A~H(왼쪽→오른쪽), 행 1~8(위→아래). 처음 배치는 1장 |
| RV-02 | 색과 선 | 흑과 백 한 명씩. 흑이 먼저 둔다 |
| RV-03 | 착수 | 빈칸에 두고, 그 돌과 같은 색 돌 사이에 상대 돌이 **한 방향 이상 연속으로 끼면** 그 방향의 상대 돌을 모두 뒤집는다 (가로·세로·대각선 8방향) |
| RV-04 | 둘 수 있는 자리 | 한 개 이상 뒤집을 수 있는 빈칸만. 아니면 거부 (`INVALID_MOVE`, 상태 변화 없음) |
| RV-05 | 넘김 | 차례인 사람이 둘 곳이 없으면 서버가 자동으로 넘기고 `turn_passed`로 알린다. 사람이 고르지 않는다 |
| RV-06 | 끝 | 둘 다 둘 곳이 없으면(판이 다 찬 경우 포함) 끝난다 |
| RV-07 | 승패 | 돌이 많은 쪽이 이긴다. 같으면 무승부 |
| RV-08 | 리매치 | 같은 방에서 다시. 흑 정하기 옵션을 다시 적용한다 |

## 3. 방 옵션

| 옵션 | 값 | 기본값 | 비고 |
| --- | --- | --- | --- |
| 흑 정하기 | 방장 / 상대 / 무작위 | 무작위 | 오목과 같다 |
| 턴 제한 시간 | 15 / 30 / 60초 | 30초 | 넘기면 서버가 대신 둔다 (RV-12) |
| 봇으로 빈자리 채우기 | 켜기 / 끄기 | 켜기 | |
| 비공개 방 | 켜기 / 끄기 | 켜기 | |

## 4. 메시지 (공통과 다른 것)

- 클라이언트 → 서버: `place { x, y, turnId }` (오목과 같은 모양)
- 서버 → 클라이언트: `stone_placed { color, x, y, flipped: [{x,y}], moveNo, isBot }`, `turn_passed { playerId }`, `game_over { result: 'count' | 'draw', winnerId, black, white }` (돌 수), 그 밖에 공통(`welcome`, `turn_start`, `player_replaced`, `error`)
- 숨긴 정보가 없는 게임이라 판은 공유 상태로 모두에게 보낸다

## 5. 시간, 퇴장, 재접속, 봇

| ID | 영역 | 규칙 |
| --- | --- | --- |
| RV-10 | 시간 | 마감 시각은 서버 기준 (S-05와 같다) |
| RV-11 | 퇴장·끊김 | 오목 G-22, G-23과 같다 (끊겨도 시간은 흐르고, 60초가 지나면 봇이 이어받는다) |
| RV-12 | 시간 초과 | 마감까지 두지 않으면 서버가 둘 수 있는 자리 중 하나를 대신 둔다(봇과 같은 판단, `isAuto`). 2번 연속이면 봇이 대신 진행하고(`autopilot`), 직접 두면 돌려받는다. 판은 끝까지 가서 돌 수로 승부한다 (원카드 C-52, 숫자야구 B-32와 같다) |
| RV-13 | 봇 | 서버 안에서 돈다. 자리 가중치(모서리 > 변 > 안쪽, 모서리 옆 칸은 피함)와 뒤집는 개수로 고른다. 1~2초 지연. 강할 필요는 없다 |
| RV-14 | 봇의 시간 | 봇이 맡은 자리는 시간 초과가 없다 |

## 6. 화면

| 화면 | 구성 | 비고 |
| --- | --- | --- |
| 대기실 | 공통 대기실 + 옵션(흑 정하기, 턴 시간) | `renderWaitingShell` |
| 대국 | 8×8 판, 흑·백 돌 수와 차례·타이머, 마지막 수 표시, 둘 수 있는 자리 점(내 차례에 **항상** 표시), 뒤집힘 연출 | 360px에서 칸이 손가락으로 눌리는 크기. **시안을 먼저 보여 준다** |
| 넘김 | "○○ 님은 둘 곳이 없어 넘어갑니다" 한 줄 알림 | |
| 결과 | 승자, 돌 수(흑 ○ : 백 ○), 이유, 리매치, 로비로 | |

입력: 마우스는 둘 수 있는 칸에 올리면 미리 보기(뒤집힐 돌 표시), 클릭으로 착수. **터치는 한 번에 착수**한다. 둘 수 있는 칸만 반응하고 칸이 커서 오착수 위험이 작다

## 7. 예외

| 상황 | 처리 | 코드 |
| --- | --- | --- |
| 뒤집을 돌이 없는 칸, 이미 돌이 있는 칸, 판 밖 | 거부 | `INVALID_MOVE` |
| 내 차례가 아님 | 거부 | `NOT_YOUR_TURN` |
| 지난 차례의 입력 | 거부 | `STALE_TURN` |
| 사람이 모두 나감 | 방 종료, 기록하지 않음 (E-10, 개수만 ST-09) | — |

## 8. 기록 (DB)

판 요약(ADR 0002, `games.summary`): 결과, 승자 색, 흑·백 돌 수, 수 개수, 넘김 횟수, 봇 여부. `/stats` 게임별 요약 지표: 평균 수, 넘김이 나온 판 비율, 시간 초과로 대신 둔 수의 비율.
