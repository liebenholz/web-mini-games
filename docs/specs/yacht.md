# 요트 주사위(yacht) 명세서 v0.1

- 작성일: 2026-11-28
- 상태: 결정 반영 (2026-11-28). 화면 시안 확인 뒤 구현한다
- 화면 이름: **요트 주사위** / 코드·주소 이름: **`yacht`** (`/yacht`, `/yacht/r/<코드>`, 방 종류 `yacht`)
- 공통 구조(방 코드, 대기실, 재접속, 봇 대체, 추방, 이탈 기록, 리매치)는 ADR 0003 공통 엔진과 `liars-dice.md`를 따른다. 이 문서는 요트 주사위에서 다른 점만 적는다
- 이름: 같은 규칙의 다른 상품명(상표)은 쓰지 않는다 (CLAUDE.md). "요트"는 오래된 전통 주사위 놀이 이름이다
- 카테고리는 `dice`(주사위). 거짓말쟁이 주사위와 달리 **숨긴 정보가 없는** 점수 경쟁 게임이다

## 1. 개요

주사위 5개를 굴려 점수표의 12칸을 하나씩 채운다. 한 차례에 최대 3번 굴리고, 마음에 드는 주사위는 남겨 두고 나머지만 다시 굴린다. 12번 차례가 끝났을 때 합계가 가장 높은 사람이 이긴다.

| 항목 | v1 결정 |
| --- | --- |
| 인원 | 2~4명 (봇 포함) + 관전. **기본 2명, 최대 4명** (2026-11-28) |
| 주사위 | 6면체 5개. 굴리는 값은 서버가 정한다 |
| 한 차례 | 최대 3번 굴리고, 점수표 빈칸 하나에 기록한다. 3번 안에 끝낼 수도 있다 |
| 점수표 | 12칸 + 보너스 (2026-11-28 결정) |
| 한 판 | 사람마다 12차례. 모두 12칸을 채우면 끝난다 |
| 승패 | 합계가 가장 높은 사람. 같으면 **공동 1위** (2026-11-28 결정) |
| 첫 차례 | 무작위. 그다음은 좌석 순서(시계 방향) |
| 턴 제한 시간 | 45초 (방 옵션). 한 차례 전체에 마감 하나 |
| 시간 초과 | 서버가 대신 둔다 (YT-12). 2번 연속이면 봇이 대신 진행 |
| 목표 플레이 시간 | 2인 약 8분, 4인 약 15분 |
| 베팅 / 재화 | 없음 |

## 2. 규칙

| ID | 규칙 | 상세 |
| --- | --- | --- |
| YT-01 | 주사위 | 6면체 5개. 굴린 값은 서버가 `rollDie`로 정하고 모두에게 공개한다 (숨긴 정보 없음) |
| YT-02 | 굴리기 | 자기 차례에 첫 번째는 주사위 5개를 모두 굴린다. 두 번째와 세 번째는 **남길 주사위를 고르고** 나머지만 다시 굴린다 (모두 남기면 굴릴 수 없다) |
| YT-03 | 기록 | 한 번이라도 굴린 뒤에는 언제든(1번, 2번, 3번째 뒤) 점수표의 **빈칸 하나**를 골라 기록하면 차례가 끝난다. 굴리기 전에는 기록할 수 없다 |
| YT-04 | 3번 뒤 | 3번째 굴림 뒤에는 더 굴릴 수 없고 기록만 할 수 있다 |
| YT-05 | 0점 기록 | 조건이 안 맞는 칸도 고를 수 있다 (0점으로 기록, 그 칸은 닫힌다) |
| YT-06 | 점수 계산 | 3장의 표를 따른다. 기록한 칸은 바꿀 수 없다 |
| YT-07 | 보너스 | 위쪽 여섯 칸(1~6의 눈) 점수의 합이 **63 이상**이면 보너스 35점이 합계에 더해진다. 63에 닿은 순간 표시하고, 합계는 늘 현재 점수 + 보너스다 |
| YT-08 | 끝 | 모든 사람이 12칸을 다 채우면 끝난다. 합계가 높은 순서로 순위를 매기고, 합계가 같으면 같은 순위다 |
| YT-09 | 리매치 | 같은 방 대기실로. 새 판에서는 첫 차례를 다시 뽑는다 |

## 3. 점수표 (YT-06)

| 칸 | 이름 | 점수 |
| --- | --- | --- |
| 1 | 1의 눈 (에이스) | 나온 1의 눈 합계 |
| 2 | 2의 눈 | 나온 2의 눈 합계 |
| 3 | 3의 눈 | 나온 3의 눈 합계 |
| 4 | 4의 눈 | 나온 4의 눈 합계 |
| 5 | 5의 눈 | 나온 5의 눈 합계 |
| 6 | 6의 눈 | 나온 6의 눈 합계 |
| 7 | 초이스 | 주사위 5개의 합계 (조건 없음) |
| 8 | 포카드 | 같은 눈이 4개 이상이면 주사위 5개의 합계, 아니면 0 |
| 9 | 풀하우스 | 한 눈 3개 + 다른 눈 2개이면 주사위 5개의 합계, 아니면 0. 같은 눈 5개(요트)는 풀하우스가 아니다 |
| 10 | 스몰 스트레이트 | 이어지는 눈 4개(1-2-3-4, 2-3-4-5, 3-4-5-6)가 있으면 15점, 아니면 0 |
| 11 | 라지 스트레이트 | 이어지는 눈 5개(1-2-3-4-5 또는 2-3-4-5-6)이면 30점, 아니면 0 |
| 12 | 요트 | 같은 눈 5개이면 50점, 아니면 0 |

### 예시

| 주사위 | 점수 |
| --- | --- |
| 4 4 4 4 2 | 4의 눈 16, 초이스 18, 포카드 18 |
| 3 3 5 5 5 | 풀하우스 21, 3의 눈 6, 5의 눈 15, 초이스 21 |
| 2 3 4 5 5 | 스몰 스트레이트 15 (라지 0) |
| 1 2 3 4 5 | 스몰 15, 라지 30 |
| 6 6 6 6 6 | 요트 50, 포카드 30, 6의 눈 30, 풀하우스 0 |

## 5. 진행

```
WAITING → STARTING(3초) → PLAYING ⟲(굴리기 · 기록) → GAME_OVER → (리매치) → WAITING
```

- PLAYING: 차례마다 `turn_start` → 굴리기 1~3번 → 기록(`scored`) → 다음 차례
- GAME_OVER: 순위와 점수표 전체 공개. 리매치 가능

## 6. 메시지 (공통과 다른 것)

숨길 정보가 없어 공유 상태로 모두에게 보낸다.

### 클라이언트 → 서버

| 이벤트 | 페이로드 | 거부 |
| --- | --- | --- |
| `roll` | `keep` (불리언 5개: 남길 주사위. 첫 번째 굴림은 모두 false여야 한다), `turnId` | 내 차례 아님(`NOT_YOUR_TURN`), 지난 `turnId`(`STALE_TURN`), 3번을 이미 굴림·모두 남김·첫 굴림에 남기려 함(`INVALID_MOVE`) |
| `score` | `category` (0~11), `turnId` | 내 차례 아님(`NOT_YOUR_TURN`), 지난 `turnId`(`STALE_TURN`), 아직 굴리지 않음·이미 기록한 칸·범위 밖(`INVALID_MOVE`) |

| 이벤트 | 대상 | 내용 |

| `scored` | 전체 | `playerId`, `category`, `points`, `upperSum`, `bonus`(35 또는 0), `total`, `isAuto`, `isBot` |

| 공통 | | `welcome`, `turn_start`, `player_replaced`, `error` |

공유 상태: `phase, roomCode, hostId, options, players(공통 필드 + seat, scores[12](빈칸은 -1), upperSum, bonus, total, autopilot, replaced), dice[5], held[5], rollNo, currentTurn, turnId, deadline, phaseEndsAt`.

## 7. 시간, 퇴장, 재접속, 봇

| ID | 영역 | 규칙 |
| --- | --- | --- |
| YT-10 | 시간 | 마감 시각은 서버 기준. 한 차례에 마감 하나 (S-05와 같다) |
| YT-11 | 퇴장·끊김 | 공통: 끊겨도 시간은 흐르고, 60초가 지나거나 스스로 나가면 봇이 이어받는다. 이어받은 봇은 이미 기록한 칸을 그대로 둔다 |
| YT-12 | 시간 초과 | 마감까지 기록하지 않았으면 서버가 대신 둔다(`isAuto`): 아직 안 굴렸다면 한 번 굴리고, 지금 주사위로 **점수가 가장 높은 빈칸**에 기록한다. 점수가 같으면 최대로 얻을 수 있는 점수가 낮은 칸을 먼저 쓴다 (0점이면 아낄 칸을 남기려고). 2번 연속이면 봇이 대신 진행하고(autopilot), 직접 굴리거나 기록하면 돌려받는다 |
| YT-13 | 봇 | 서버 안에서 돈다. 1~2초 간격으로 행동한다. 굴림마다 가장 많이 나온 눈(또는 스트레이트에 가까운 눈)을 남기고, 요트·라지 스트레이트처럼 이미 좋은 모양이면 바로 기록한다. 칸은 "점수 − 그 칸의 평균 기대 점수"가 가장 큰 곳을 고른다 |
| YT-14 | 봇의 시간 | 봇이 맡은 자리는 시간 초과가 없다 |

## 8. 화면

| 화면 | 구성 | 비고 |
| --- | --- | --- |
| 대기실 | 공통 대기실 + 옵션(최대 인원, 턴 시간) | `renderWaitingShell` |
| 게임 | 위: 참가자(합계, 차례 표시, 시간 막대). 가운데: **주사위 5개**(내 차례에 누르면 "남김" 표시), **굴리기 (n번 남음)** 버튼. 아래: **점수표** — 칸 이름 12줄 × 참가자 열(최대 4명), 위쪽 소계와 보너스 줄, 합계 줄. 내 차례에는 빈칸 옆에 **지금 주사위로 얻을 점수**를 미리 보여 주고, 누르면 선택, "기록" 버튼으로 확정 | 360px에서 4명 열이 들어간다. **시안을 먼저 보여 준다** |
| 결과 | 순위, 합계, 점수표 전체, 다시 하기 / 나가기 | 동점이면 공동 1위 표시 |

입력: 주사위를 누르면 남김/굴림이 바뀐다. 굴리기 후에는 남김 표시가 풀리지 않고 다음 굴림의 기본값이 된다. 점수표 칸을 눌러 고른 뒤 "기록"으로 확정한다(실수로 칸을 잘못 쓰는 것을 막는다). 키보드: 1~5로 주사위 남김 토글, R로 굴리기, ↑↓로 칸 선택(이동), Enter 또는 Space로 기록.

연출: 굴릴 때 굴러가는 주사위(0.5초), 요트가 나오면 "요트!" 강조. 동작 줄이기 설정이면 바로 값만 바뀐다.

## 10. 기록 (DB)

판 요약(ADR 0002, `games.summary`): 인원, 사람별 합계, 보너스를 받은 사람 수, 요트가 나온 횟수(`yachts`), 차례 수(`moveCount`), 대신 둔 차례 수(`autoMoveCount`), 봇 여부. 순위는 합계 순서(공동 순위는 같은 값, 자기보다 합계가 높은 사람 수 + 1). `/stats` 게임별 지표: 평균 합계, 보너스 비율, 시간 초과로 대신 둔 비율.
