# 원카드(one-card) 명세서 v0.1 (초안)

- 작성일: 2026-11-24
- 상태: 결정 반영 (2026-11-24). 승인되면 Phase 2 M3 구현을 시작한다
- 화면 이름: **원카드** / 코드·주소 이름: **`one-card`** (`/one-card`, `/one-card/r/<코드>`), 서버 방 종류 **`one_card`**
- 공통 구조(방 코드, 대기실, 재접속, 봇, 추방)는 거짓말쟁이 주사위 명세(`liars-dice.md`)와 ADR 0002를 따른다. 이 문서는 원카드에서 다른 점만 적는다.

## 1. 개요

2~6명이 트럼프 카드로 하는 게임이다. 맨 위 카드와 모양이나 숫자가 같은 카드를 한 장씩 내고, 패를 먼저 다 내면 이긴다. 공격 카드로 다음 사람에게 카드를 떠넘기고, 공격은 받아쳐서 쌓을 수 있다. 패가 1장 남으면 "원카드"를 먼저 외쳐야 한다.

| 항목                 | v1 결정                                                                     |
| -------------------- | --------------------------------------------------------------------------- |
| 인원                 | 2~6명 (빈자리는 봇) + 관전                                                  |
| 덱                   | 54장: 트럼프 52장 + 흑백 조커 1장 + 컬러 조커 1장                           |
| 시작 패              | 한 사람당 7장                                                               |
| 공격                 | 2(+2), A(+3), 흑백 조커(+5), 컬러 조커(+7). 받아치면 누적                   |
| 특수                 | 7 모양 바꾸기, J 건너뛰기, Q 방향 바꾸기, K 한 번 더                        |
| 원카드 외치기 | 패가 1장이 되면 모두에게 버튼. 먼저 누른 쪽으로 판정. 창이 닫힐 때까지 게임이 멈춘다 |
| 파산                 | 패가 20장을 넘으면 탈락                                                     |
| 승리                 | 먼저 다 낸 사람이 1위. 한 명이 남을 때까지 계속해서 순위를 매긴다           |
| 턴 시간 초과         | 자동으로 카드를 가져오고 차례를 넘긴다. 2번 연속이면 봇이 대신 둔다         |
| 게임 중 퇴장         | 봇이 패를 이어받는다                                                        |
| 베팅 / 재화          | 없음                                                                        |

## 2. 카드

| ID   | 규칙       | 상세                                                                                                                         |
| ---- | ---------- | ---------------------------------------------------------------------------------------------------------------------------- |
| C-01 | 덱         | 모양 4개(♠ ♥ ◆ ♣) × 숫자 13개(A, 2~10, J, Q, K) + 흑백 조커 + 컬러 조커 = 54장. 서버가 `crypto.randomInt`로 섞는다            |
| C-02 | 카드 표기  | 모양 `S` `H` `D` `C` + 숫자 `A` `2`~`10` `J` `Q` `K` (예: `S7`, `HA`, `D10`). 조커는 `JB`(흑백), `JC`(컬러). 클로버 J(`CJ`)와 겹치지 않게 조커는 `J`로 시작한다                     |
| C-03 | 나눠 주기  | 한 사람당 7장. 남은 카드는 뒤집은 덱이 된다                                                                                  |
| C-04 | 첫 카드    | 덱 맨 위 카드를 펼쳐 버린 카드 더미에 놓는다. **숫자 카드(3~6, 8~10)가 나올 때까지** 특수 카드는 덱 맨 아래로 넣고 다시 편다 |
| C-05 | 첫 차례    | 서버가 무작위로 정한다. 처음 방향은 좌석 번호 오름차순(시계 방향)                                                            |

## 3. 내기 규칙

| ID   | 규칙                | 상세                                                                                                                                       |
| ---- | ------------------- | ------------------------------------------------------------------------------------------------------------------------------------------ |
| C-10 | 낼 수 있는 카드     | 공격을 받고 있지 않으면: 맨 위 카드와 **모양이 같거나 숫자가 같은** 카드. 조커는 언제나 낼 수 있다                                         |
| C-11 | 조커 다음           | 맨 위가 조커이고 공격이 끝났으면(누가 받아 먹었으면) 다음 사람은 아무 카드나 낼 수 있다                                                    |
| C-12 | 7 다음 | 7을 낸 사람이 모양을 고른다. 다음 사람은 **고른 모양**의 카드, 다른 7, 또는 조커만 낼 수 있다. 7 위에 7을 내면 **새로 낸 사람이 모양을 다시 고른다** |
| C-13 | 한 번에 한 장       | 한 차례에 한 장만 낸다 (같은 숫자 여러 장 한꺼번에 내기 없음). 단 K는 C-23                                                                 |
| C-14 | 가져오기            | 낼 카드가 없거나 내고 싶지 않으면 덱에서 1장 가져온다. **가져온 카드를 낼 수 있으면 그 차례에 바로 낼 수 있다.** 내지 않으면 차례를 넘긴다 |
| C-15 | 덱이 떨어지면       | 버린 카드 더미에서 맨 위 1장만 남기고 나머지를 섞어 새 덱으로 쓴다. 그래도 모자라면 있는 만큼만 가져온다                                  |

## 4. 공격과 특수 카드

| ID   | 카드              | 상세                                                                                                                                                     |
| ---- | ----------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------- |
| C-20 | 공격              | 2 = +2, A = +3, 흑백 조커 = +5, 컬러 조커 = +7. 공격 카드를 내면 다음 사람이 공격을 받는다                                                               |
| C-21 | 받아치기와 누적   | 공격을 받은 사람은 **공격 카드로만** 받아칠 수 있고, 받아치면 장수가 더해져 다음 사람에게 간다. 받아칠 수 있는 카드는 아래 표                            |
| C-22 | 받아 먹기         | 받아치지 않으면(또는 못 하면) 누적된 장수를 모두 가져오고 **그 차례는 끝난다** (C-14의 "가져와서 바로 내기"는 공격에 적용하지 않는다). 공격은 사라진다 |
| C-23 | K 한 번 더        | K를 내면 같은 사람이 한 번 더 낸다. 낼 카드가 없으면 C-14대로 가져온다                                                                                   |
| C-24 | J 건너뛰기        | 다음 사람을 건너뛴다                                                                                                                                     |
| C-25 | Q 방향 바꾸기     | 진행 방향이 반대가 된다. **2명일 때는 J와 같다** (내가 한 번 더)                                                                                         |
| C-26 | 7 모양 바꾸기     | C-12. 공격 중에는 낼 수 없다                                                                                                                             |

**공격 중 받아칠 수 있는 카드 (C-21)**

| 맨 위 공격 카드 | 받아칠 수 있는 카드                                                                       |
| --------------- | ----------------------------------------------------------------------------------------- |
| 2 또는 A        | 맨 위 카드와 **모양이 같거나 숫자가 같은** 공격 카드(2, A) + 흑백 조커 + 컬러 조커         |
| 흑백 조커       | 컬러 조커만                                                                               |
| 컬러 조커       | 없음 (받아 먹는다)                                                                        |

- 예: 맨 위가 ♥2면 아무 모양의 2, ♥A, 두 조커로 받아칠 수 있다. ♠A로는 못 한다.
- 조커로 받아친 뒤의 맨 위 카드는 조커다. 공격이 끝나면 C-11이 적용된다.

## 5. 원카드 외치기, 파산, 순위

| ID   | 규칙               | 상세                                                                                                                                                                       |
| ---- | ------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| C-30 | 외치기 창 | 카드를 내서 패가 **1장**이 되면 최대 3초 동안 "원카드" 창이 열린다. 모든 참가자(관전자 제외, 대상 본인 포함) 화면에 버튼이 뜬다. 봇이 대상이어도 같다 |
| C-31 | 판정 | **본인이 먼저 누르면 안전.** 다른 사람이 먼저 누르면 본인이 덱에서 1장을 가져온다 (벌칙). 서버에 먼저 도착한 누르기 하나만 처리하고 **그 즉시 창이 닫힌다.** 3초 안에 아무도 누르지 않으면 벌칙 없이 닫힌다 |
| C-32 | 창 동안 멈춤 | 창이 열려 있는 동안에는 **다음 차례를 시작하지 않는다** (turnId 발급 없음, 턴 타이머 멈춤, K로 같은 사람이 한 번 더 내는 경우도 같다). 이때 온 `play`·`draw`·`pass`는 거부한다. 창이 닫힌 뒤에 다음 차례가 시작되므로 누르기와 카드 내기가 경합하지 않는다 |
| C-33 | 다 냄              | 패가 0장이 되면 그 사람은 끝난다(순위 확정). 마지막 카드의 효과(공격, J, Q, 7)는 그대로 다음 사람에게 적용된다. 마지막 카드가 K면 한 번 더 없이 바로 끝난다             |
| C-34 | 파산 | 카드를 가져와서 패가 **20장을 넘으면** 바로 탈락한다. 그 패는 버린 카드 더미의 **맨 아래**로 들어간다 (맨 위의 펼친 카드와 고른 모양, 차례 진행은 그대로). 받아 먹던 공격은 사라진다 |
| C-35 | 순위               | 다 낸 순서대로 1위, 2위, … 마지막으로 남은 1명이 그다음 순위. 파산한 사람은 그 뒤이고, 늦게 파산한 사람이 더 높다                                                       |
| C-36 | 게임 끝            | 패를 가진 사람이 1명만 남으면 끝난다                                                                                                                                       |
| C-37 | 리매치             | 같은 방에서 다시 시작한다. 첫 차례는 다시 무작위                                                                                                                          |

## 6. 진행

```
WAITING → STARTING → PLAYING ⟲(낸다 / 가져온다) → GAME_OVER → (리매치) → WAITING
```

1. 대기실: 방장이 옵션(최대 인원, 턴 시간, 봇 채우기)을 고른다. 2명 이상(봇 포함)이고 모두 준비하면 방장이 시작한다.
2. 시작: 덱을 섞고 7장씩 나눠 준 뒤 첫 카드를 편다(C-04). 각자 자기 패만 받는다.
3. 진행: 차례인 사람이 카드를 내거나(C-10~C-12) 가져온다(C-14). 서버가 공격, 특수 효과, 방향, 다음 차례를 계산한다.
4. 종료: 한 명만 남으면(C-36) 순위를 보여 준다.

## 7. 방 옵션

| 옵션                 | 값             | 기본값 | 비고                               |
| -------------------- | -------------- | ------ | ---------------------------------- |
| 최대 인원            | 2~6            | 4      |                                    |
| 턴 제한 시간         | 15 / 30 / 60초 | 30초   | 거짓말쟁이 주사위·오목과 같은 선택지 |
| 봇으로 빈자리 채우기 | 켜기 / 끄기    | 켜기   |                                    |
| 비공개 방            | 켜기 / 끄기    | 켜기   |                                    |

- 시작 패(7장), 파산 기준(20장), 외치기 창(3초)은 옵션이 아니라 고정값이다.

## 9. 메시지 프로토콜 (원카드에서 다른 것)

공통 대기실 메시지(`set_ready`, `start_game`, `set_options`, `add_bot`, `remove_bot`, `kick_player`, `rematch`, `leave_room`)는 거짓말쟁이 주사위와 같다.

### 클라이언트 → 서버

| 이벤트          | 페이로드                          | 허용 상태 | 거부 조건                                                                                                                                         |
| --------------- | --------------------------------- | --------- | ------------------------------------------------------------------------------------------------------------------------------------------------- |
| `play`          | card, suit(7일 때만), turnId      | PLAYING   | 내 차례 아님(`NOT_YOUR_TURN`), 내 패에 없음·낼 수 없음(`INVALID_CARD`), 7인데 모양이 없거나 잘못됨(`INVALID_SUIT`), 만료된 turnId(`STALE_TURN`) |
| `draw`          | turnId                            | PLAYING   | 내 차례 아님, 이번 차례에 이미 가져옴(`INVALID_STATE`), 만료된 turnId                                                                             |
| `pass`          | turnId                            | PLAYING   | 가져오기 전(`INVALID_STATE`). 가져온 카드를 내지 않고 넘길 때만 쓴다                                                                              |
| `call_one_card` | windowId | PLAYING | 창이 닫힘·없음(`STALE_TURN`), 관전자·다 낸 사람·파산한 사람(`INVALID_STATE`) |

### 서버 → 클라이언트

| 이벤트             | 대상   | 내용                                                                                                |
| ------------------ | ------ | --------------------------------------------------------------------------------------------------- |
| 공유 상태          | 전체   | 플레이어(닉네임, 패 장수, 상태), 맨 위 카드, 고른 모양, 공격 누적, 방향, 덱 장수, 현재 차례, 마감 시각 |
| `your_hand`        | 본인만 | 내 패 전체 (나눠 줄 때, 가져올 때, 재접속할 때)                                                     |
| `turn_start`       | 전체   | playerId, turnId, 마감 시각, 공격 중인지                                                            |
| `card_played`      | 전체   | playerId, card, 고른 모양, 남은 장수, 자동 행동 여부                                                |
| `cards_drawn`      | 전체   | playerId, 장수, 이유(`draw` / `attack` / `penalty`). **카드는 넣지 않는다**                         |
| `one_card_window`  | 전체   | windowId, 대상 playerId, 닫히는 시각                                                                |
| `one_card_called`  | 전체   | windowId, 누른 사람, 대상, 결과(`safe` / `penalty`)                                                 |
| `player_finished`  | 전체   | playerId, 순위                                                                                      |
| `player_bankrupt`  | 전체   | playerId                                                                                            |
| `player_replaced`  | 전체   | 오목과 같다 (`left` / `disconnected` / `returned`)                                                  |
| `game_over`        | 전체   | 최종 순위                                                                                           |

## 10. 시간, 퇴장, 재접속, 봇

| ID   | 영역      | 규칙                                                                                                                                                               |
| ---- | --------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| C-50 | 시간      | 마감 시각은 서버 기준 (S-05와 같다)                                                                                                                                |
| C-51 | 자동 행동 | 마감까지 아무것도 안 하면: 공격 중이면 받아 먹고(C-22), 아니면 1장 가져오고 차례를 넘긴다 (가져온 카드를 내지 않는다). 이미 가져온 뒤면 그냥 넘긴다              |
| C-52 | 봇 대신   | 2턴 연속 자동 행동이면 봇이 대신 둔다. 그 사람이 다시 무언가를 보내면 돌려받는다 (S-07과 같다)                                                                     |
| C-53 | 가져온 뒤 | 가져온 뒤에는 같은 마감 시각 안에 내거나 넘긴다. 남은 시간이 5초보다 적으면 5초로 늘린다                                                                           |
| C-54 | 연결 끊김 | 60초 동안 자리를 유지한다. 그 사이 차례가 오면 C-51을 적용한다. 60초가 지나면 봇이 이어받는다 (S-08, S-10과 같다)                                                |
| C-55 | 퇴장      | 게임 중 스스로 나가면 바로 봇이 패를 이어받는다. 다른 사람에게 알린다                                                                                              |
| C-56 | 봇 판단   | 자기 패와 공개 정보만 쓴다. 받아칠 수 있으면 받아친다 → 공격 카드는 아끼고 숫자 카드부터 낸다 → 7은 가장 많이 가진 모양으로 → 낼 게 없으면 가져온다. 1~2초 뒤 행동 |
| C-57 | 봇 외치기 | 봇이 대상인 창에서 봇은 **1~2초 사이 무작위**로 누른다. 사람이 그보다 먼저 누르면 봇이 벌칙을 받는다 (사람과 같은 규칙). 봇은 남의 창을 누르지 않는다 |

## 13. 기록 (DB)

## 15. 결정 기록

2026-11-24에 정했다.

- 덱 54장(조커 2장), 시작 패 7장
- 공격: 2(+2), A(+3), 흑백 조커(+5), 컬러 조커(+7). 공격 카드로만 받아치고 누적. 받아칠 때도 모양·숫자가 맞아야 하고, 조커는 언제나 된다. 조커 공격은 조커로만, 컬러 조커는 흑백 조커로 못 받는다
- 특수 카드 7, J, Q, K 모두 넣는다. 2인일 때 Q는 J와 같다. K를 마지막 장으로 내면 바로 끝난다
- 원카드 외치기: 1장이 되면 모두에게 버튼, 먼저 누른 쪽으로 판정, 3초 동안 아무도 안 누르면 넘어간다
- 파산: 20장 초과. 승리: 끝까지 순위
- 가져오기: 1장 가져와서 낼 수 있으면 그 차례에 바로 낼 수 있다
- 시간 초과: 자동 가져오기, 2번 연속이면 봇. 턴 시간 15 / 30 / 60초, 기본 30초

### 검토 반영 (2026-11-24)

- 공격을 받아 먹으면 그 차례는 끝난다. 가져와서 바로 내기는 평소 가져올 때만 (C-22)
- 7 다음에는 고른 모양, 다른 7, 조커. 7 위에 7을 내면 모양을 다시 고른다 (C-12)
- 첫 카드는 숫자 카드(3~6, 8~10)가 나올 때까지 다시 편다 (C-04)
- 원카드 창이 열린 동안 게임을 멈춘다. 누가 누르면 바로 닫히고, 그 뒤에 다음 차례가 시작된다 (C-32). 창과 다음 차례가 같이 흐르면 대상이 마지막 카드를 내는 것과 남이 누르는 것이 경합하기 때문이다
- 봇도 자기 창을 1~2초 사이에 누르고, 사람이 먼저 누르면 벌칙을 받는다. 봇은 남의 창을 누르지 않는다 (C-57)
- 파산한 패는 버린 카드 더미 맨 아래로 들어간다 (C-34)
- 최대 인원 기본 4명, 가져온 뒤 남은 시간이 5초 미만이면 5초로, 게임이 끝나도 남은 패는 공개하지 않는다
