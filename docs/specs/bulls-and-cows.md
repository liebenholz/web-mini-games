# 숫자야구(bulls-and-cows) 명세서 v0.1 (초안)

- 작성일: 2026-11-25
- 상태: 초안. 13장 "검토할 기본값"을 확인받으면 Phase 2 M4 구현을 시작한다
- 화면 이름: **숫자야구** / 코드·주소 이름: **`bulls-and-cows`** (`/bulls-and-cows`, `/bulls-and-cows/r/<코드>`), 서버 방 종류 **`bulls_and_cows`**
- 영어권 이름: Bulls and Cows (특정 회사 상품이 아닌 전래 게임 이름). 이 게임을 상품화한 보드게임 이름은 상표라서 쓰지 않는다
- 공통 구조(방 코드, 대기실, 재접속, 봇, 추방)는 거짓말쟁이 주사위 명세(`liars-dice.md`)와 ADR 0002를 따른다. 이 문서는 숫자야구에서 다른 점만 적는다.

## 1. 개요

2명이 각자 비밀 숫자를 정하고, 번갈아 상대의 숫자를 추측한다. 추측할 때마다 숫자와 자리가 모두 맞으면 **스트라이크**, 숫자만 맞으면 **볼**, 하나도 없으면 3자리는 **OUT**으로 알려 준다. 상대 숫자를 먼저 맞히면 이긴다. 결과 표기는 3자리면 숫자야구 식(`1S 2B`), 4자리면 Bulls and Cows 식(`1B 2C`)이다 (B-11).

| 항목              | v1 결정                                                                    |
| ----------------- | -------------------------------------------------------------------------- |
| 인원              | 2명 (빈자리는 봇) + 관전                                                   |
| 자릿수            | 방장이 3 / 4자리 중 고른다. 기본 3자리                                     |
| 숫자              | 0~9, 중복 없음. 맨 앞에 0도 된다 (예: 012)                                 |

| 승부              | 먼저 맞히면 이긴다. 선공이 먼저 맞히면 후공에게 같은 횟수로 마지막 기회     |
| 시도 제한         | 방장이 10 / 15 / 제한 없음 중 고른다 (기본 10). 둘 다 못 맞히면 무승부               |
| 턴 시간 초과      | 그 턴을 넘긴다 (시도 횟수에 들어간다). 2번 연속이면 봇이 대신 추측한다     |

| 베팅 / 재화       | 없음                                                                       |

## 2. 규칙

| ID   | 규칙          | 상세                                                                                                                                         |
| ---- | ------------- | -------------------------------------------------------------------------------------------------------------------------------------------- |
| B-01 | 비밀 숫자     | 자릿수(3 또는 4)만큼 0~9 숫자를 중복 없이 고른다. 순서가 있다 (예: 3자리 `102`)                                                               |
| B-02 | 추측          | 자기 차례에 비밀 숫자와 같은 형식(자릿수, 0~9, 중복 없음)의 숫자를 낸다. 형식이 틀리면 거부한다 (`INVALID_GUESS`)                           |
| B-03 | 판정 | 상대 비밀 숫자와 비교해 **스트라이크** = 숫자와 자리가 같은 개수, **볼** = 숫자는 있지만 자리가 다른 개수. 둘 다 0이면 3자리는 **OUT**, 4자리는 `0B 0C` (B-11) |
| B-04 | 공개          | 추측과 판정 결과는 두 사람과 관전자 모두에게 보인다. 비밀 숫자는 게임이 끝날 때까지 본인만 안다                                            |
| B-05 | 맞힘          | 스트라이크가 자릿수와 같으면 (3자리 `3S`, 4자리 `4B 0C`) 상대 숫자를 맞힌 것이다                                                                                |
| B-06 | 선후공        | 서버가 무작위로 선공을 정한다. 선공부터 번갈아 추측한다                                                                                     |
| B-07 | 승리          | 후공이 맞히면 바로 이긴다. 선공이 맞히면 후공에게 **마지막 기회** 한 번(같은 시도 횟수가 되도록)을 준다. 후공도 맞히면 무승부, 못 맞히면 선공 승리 |
| B-08 | 시도 제한     | 각자 시도 횟수가 방 옵션의 제한에 이르면 더 추측하지 않는다. 둘 다 제한까지 못 맞히면 무승부                                                |
| B-09 | 시도 횟수     | 추측 한 번, 시간 초과로 넘긴 턴 한 번이 각각 시도 1회다                                                                                     |
| B-10 | 리매치        | 같은 방에서 다시 시작한다. 비밀 숫자를 새로 정하고 선공도 다시 무작위                                                                       |
| B-11 | 결과 표기 | **3자리 (숫자야구 식)**: 스트라이크 `S`, 볼 `B`. 0인 쪽은 생략한다 (예: `1S 2B`, `2S`, `3B`). 둘 다 0이면 `OUT`. **4자리 (Bulls and Cows 식)**: 자리까지 맞음 = Bull `B`, 숫자만 맞음 = Cow `C`. 0도 표기한다 (예: `1B 2C`, `0B 4C`, `4B 0C`). 둘 다 0이면 `0B 0C`. 글자로 풀어 쓰면(1 Bull and 2 Cows) 너무 길어서 줄여 쓴다. 서버는 숫자(스트라이크 수, 볼 수)만 보내고 표기는 화면이 정한다 |

### 판정 예시 (3자리, 상대 비밀 숫자 `102`)

| 추측  | 결과   | 이유                                         |
| ----- | ------ | -------------------------------------------- |
| `345` | OUT    | 1, 0, 2가 하나도 없다                        |
| `120` | 1S 2B  | 1은 자리까지 맞음, 2와 0은 있지만 자리가 다름 |
| `152` | 2S     | 1과 2는 자리까지 맞음                        |
| `102` | 3S     | 맞힘                                         |

## 3. 진행

```
WAITING → STARTING → SECRET → PLAYING ⟲(추측) → GAME_OVER → (리매치) → WAITING
```

1. 대기실: 방장이 옵션(자릿수, 시도 제한, 턴 시간)을 고른다. 2명이 되면(또는 빈자리 봇) 방장이 시작한다.
2. 비밀 숫자(SECRET, 60초): 각자 비밀 숫자를 정한다. "무작위로 정하기" 버튼도 있다. 둘 다 정하면 바로 다음으로, 60초가 지나면 아직 안 정한 사람은 서버가 무작위로 정한다. 한 번 정하면 바꿀 수 없다.
3. 추측(PLAYING): 선공부터 번갈아 추측한다 (B-06). 결과는 모두에게 보인다.
4. 끝: 승리, 무승부 중 하나로 끝나고 두 사람의 비밀 숫자를 공개한다.

## 4. 방 옵션

| 옵션                 | 값                     | 기본값 | 비고                                     |
| -------------------- | ---------------------- | ------ | ---------------------------------------- |
| 자릿수               | 3 / 4                  | 3      | 3자리는 보통 5~7번, 4자리는 7~10번에 맞힌다 |
| 시도 제한            | 10 / 15 / 제한 없음    | 10     |                                          |
| 턴 제한 시간         | 15 / 30 / 60초         | 30초   | 넘기면 그 턴을 넘긴다                    |
| 봇으로 빈자리 채우기 | 켜기 / 끄기            | 켜기   |                                          |
| 비공개 방            | 켜기 / 끄기            | 켜기   |                                          |

- 비밀 숫자를 정하는 시간(60초)은 옵션이 아니라 고정값이다.

## 6. 메시지 프로토콜 (숫자야구에서 다른 것)

공통 대기실 메시지(`set_ready`, `start_game`, `set_options`, `add_bot`, `remove_bot`, `kick_player`, `rematch`, `leave_room`)는 다른 게임과 같다.

### 클라이언트 → 서버

| 이벤트          | 페이로드              | 허용 상태 | 거부 조건                                                                                                          |
| --------------- | --------------------- | --------- | ------------------------------------------------------------------------------------------------------------------ |
| `set_secret`    | digits (문자열)       | SECRET    | 형식이 틀림(`INVALID_GUESS`), 이미 정함(`INVALID_STATE`), 관전자(`INVALID_STATE`)                                  |
| `random_secret` | —                     | SECRET    | 이미 정함(`INVALID_STATE`)                                                                                         |
| `guess`         | digits, turnId        | PLAYING   | 내 차례 아님(`NOT_YOUR_TURN`), 형식이 틀림(`INVALID_GUESS`), 만료된 turnId(`STALE_TURN`)                           |

### 서버 → 클라이언트

| 이벤트         | 대상   | 내용                                                                                           |
| -------------- | ------ | ---------------------------------------------------------------------------------------------- |
| 공유 상태      | 전체   | 플레이어(닉네임, 비밀 숫자를 정했는지, 시도 횟수), 추측 기록(누가, 숫자, S, B), 차례, 마감 시각 |
| `your_secret`  | 본인만 | 내 비밀 숫자                                                                                   |
| `turn_start`   | 전체   | playerId, turnId, 마감 시각, 마지막 기회인지                                                   |
| `guess_result` | 전체   | playerId, 추측, 스트라이크, 볼, 몇 번째 시도, 봇이 대신했는지                                  |
| `turn_skipped` | 전체   | playerId, 몇 번째 시도 (시간 초과)                                                             |
| `last_chance`  | 전체   | 후공 playerId (B-07)                                                                           |
| `game_over`    | 전체   | 결과(`solved` 맞힘 / `draw` 무승부), 이긴 사람, 두 사람의 비밀 숫자, 각자 시도 횟수            |

## 10. 기록 (DB)

오목·원카드와 같이 **판 요약**만 저장한다 (ADR 0002, `games.summary`).

- `games`: `game_type = 'bulls_and_cows'`, `options`, `end_reason`(`solved` / `draw`), `summary`(JSON: 자릿수, 각자 시도 횟수, 마지막 기회가 있었는지, 시간 초과로 넘긴 턴 수, 봇 여부)
- `game_players`: 자리 0 = 선공, 1 = 후공. 이긴 쪽 1, 진 쪽 2, 무승부면 둘 다 1
- 비밀 숫자와 추측 내용은 저장하지 않는다

## 12. 결정 기록

2026-11-25에 정했다.

- 이름: 화면은 "숫자야구", 코드·주소는 `bulls-and-cows` (영어권 이름)
- 2인 대결. 빈자리는 봇

- 숫자: 0~9, 중복 없음
- 승부: 후공에게 마지막 기회 (같은 횟수가 되도록 한 번 더). 둘 다 맞히면 무승부
- 비밀 숫자: 60초 안에, 못 정하면 무작위
- 턴 시간: 15 / 30 / 60초, 기본 30초. 넘기면 그 턴을 넘기고 시도 횟수에 넣는다. 2번 연속이면 봇
- 시도 제한: 방장이 정함 (10 / 15 / 제한 없음), 기본 10
- 메모판: 넣음 (내 화면 전용)
- 결과 표기: 3자리 `1S 2B`(숫자야구 식, 0 생략, 없으면 `OUT`), 4자리 `1B 2C`(Bulls and Cows 식, 0 표기, 없으면 `0B 0C`)
