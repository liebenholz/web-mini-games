## 1. 개요

모두 함께 풍선 하나에 바람을 넣는다. 차례가 오면 펌프를 1~3번 누르고 넘긴다. 풍선은 아무도 모르는 횟수에서 터지고, 터뜨린 사람이 당첨되어 판이 바로 끝난다.

| 항목 | v1 결정 |
| --- | --- |
| 인원 | 2~6명 (봇 포함) + 관전 |
| 한 차례 | 펌프를 **한 번씩** 누른다. 1번 이상 누르면 넘길 수 있고, 3번 누르면 자동으로 넘어간다 (2026-11-27 결정) |
| 터지는 횟수 | 5 ~ (참가 인원 × 4 + 12)번 중 서버가 무작위로 정한다. 범위는 공개, 정확한 값은 비공개 |
| 화면 정보 | 풍선 크기와 **지금까지 누른 횟수**를 보여 준다 (2026-11-27 결정) |
| 당첨 | 1명. 터뜨린 사람. 바로 끝 |
| 첫 차례 | 무작위 |
| 턴 제한 시간 | 15초 (방 옵션) |
| 시간 초과 | 서버가 대신 누른다 (BL-12) |
| 목표 플레이 시간 | 1~3분 |
| 베팅 / 재화 | 없음 |

## 2. 규칙

| ID | 규칙 | 상세 |
| --- | --- | --- |
| BL-01 | 터지는 횟수 | 판이 시작될 때 서버가 5 이상 (인원 × 4 + 12) 이하의 정수 하나를 `crypto.randomInt`로 고른다. 2명이면 5~20, 6명이면 5~36. 판이 끝날 때까지 바뀌지 않는다 |
| BL-02 | 차례 | 첫 차례는 무작위. 그다음은 좌석 번호 순(시계 방향) |
| BL-03 | 펌프 | 자기 차례에 펌프를 한 번 누를 때마다 전체 횟수가 1 늘고, 바로 결과가 나온다 |
| BL-04 | 넘기기 | 이번 차례에 1번 이상 눌렀으면 넘길 수 있다. 0번이면 넘길 수 없다 (`INVALID_MOVE`) |
| BL-05 | 최대 3번 | 한 차례에 3번째를 누르고 안 터지면 자동으로 다음 사람에게 넘어간다. 4번째는 거부 (`INVALID_MOVE`) |
| BL-06 | 당첨 | 전체 횟수가 터지는 횟수에 닿은 펌프를 누른 사람이 당첨되고 판이 바로 끝난다. 터지는 횟수를 공개한다 |
| BL-07 | 리매치 | 같은 방 대기실로. 새 판에서는 터지는 횟수와 첫 차례를 다시 뽑는다 |

### 예시 (3명, 터지는 범위 5~24, 실제 14)

| 차례 | 누름 | 전체 | 결과 |
| --- | --- | --- | --- |
| A | 3번 | 3 | 자동으로 넘어감 |
| B | 2번 → 넘기기 | 5 | |
| C | 3번 | 8 | 자동으로 넘어감 |
| A | 1번 → 넘기기 | 9 | |
| B | 3번 | 12 | 자동으로 넘어감 |
| C | 2번째에서 펑 | 14 | **C 당첨**, 끝 |

## 3. 진행

```
WAITING → STARTING(3초) → PLAYING ⟲(펌프·넘기기) → GAME_OVER → (리매치) → WAITING
```

- STARTING: 좌석 확정, 터지는 횟수와 첫 차례 뽑기
- PLAYING: 차례마다 `turn_start` → 펌프 1~3번(`pumped`) → 넘기기 또는 3번째 뒤 자동 → 다음 `turn_start`
- GAME_OVER: 당첨자와 터지는 횟수 공개. 리매치 가능

## 4. 방 옵션

| 옵션 | 값 | 기본값 | 비고 |
| --- | --- | --- | --- |
| 최대 인원 | 2~6 | 6 | 지금 인원보다 줄일 수 없다 |
| 턴 제한 시간 | 10 / 15 / 30초 | 15초 | 업다운과 같다. 한 차례(1~3번 누르기) 전체의 시간 |
| 봇으로 빈자리 채우기 | 켜기 / 끄기 | 켜기 | |
| 비공개 방 | 켜기 / 끄기 | 켜기 | |

터지는 범위는 옵션으로 두지 않는다 (인원으로 정해진다). 당첨은 늘 1명이다.

## 6. 메시지 (공통과 다른 것)

### 클라이언트 → 서버

| 이벤트 | 페이로드 | 거부 |
| --- | --- | --- |
| `pump` | `turnId` | `NOT_YOUR_TURN`, `STALE_TURN`, `INVALID_MOVE`(이번 차례에 이미 3번) |
| `end_turn` | `turnId` | `NOT_YOUR_TURN`, `STALE_TURN`, `INVALID_MOVE`(이번 차례에 아직 0번) |

### 서버 → 클라이언트

| 이벤트 | 대상 | 내용 |
| --- | --- | --- |
| `pumped` | 전체 | `playerId`, `total`(전체 횟수), `turnPumps`(이번 차례 몇 번째), `popped`, `isAuto`, `isBot` |
| `game_over` | 전체 | `loserId`(당첨자), `threshold`(터지는 횟수) |
| 공통 | | `welcome`, `turn_start`, `player_replaced`, `error` |

공유 상태: `phase, roomCode, hostId, options, players(공통 필드 + seat, autopilot, replaced), total, turnPumps, maxPops(공개된 범위의 최대값 = 인원 × 4 + 12), history[](playerId, pumps, isAuto), currentTurn, turnId, deadline, phaseEndsAt, loserId, threshold(끝난 뒤에만 채움)`.

## 7. 시간, 퇴장, 재접속, 봇

| ID | 영역 | 규칙 |
| --- | --- | --- |
| BL-10 | 시간 | 마감 시각은 서버 기준 (S-05와 같다). 한 차례 전체에 하나의 마감 |
| BL-11 | 퇴장·끊김 | 공통: 끊겨도 시간은 흐르고, 60초가 지나거나 스스로 나가면 봇이 이어받는다 |
| BL-12 | 시간 초과 | 마감까지 **한 번도 안 눌렀으면** 서버가 1~3번 중 무작위 횟수만큼 대신 누른다(`isAuto`, 0.4초 간격으로 보여 준다). 2번 연속이면 봇이 대신 진행하고, 직접 누르면 돌려받는다. **이미 1번 이상 눌렀으면** 시간 초과는 그냥 넘기기로 처리하고 연속 시간 초과로 세지 않는다 |
| BL-13 | 봇 | 서버 안에서 돈다. 1~3번 중 무작위 횟수를 0.4~0.8초 간격으로 누른다. 1~2초 생각한 뒤 시작한다 |
| BL-14 | 봇의 시간 | 봇이 맡은 자리는 시간 초과가 없다 |

무작위로 대신 누르는 이유: 항상 1번만 누르면 일부러 시간을 넘기는 쪽이 유리해진다 (2026-11-27 결정).

## 8. 화면

| 화면 | 구성 | 비고 |
| --- | --- | --- |
| 대기실 | 공통 대기실 + 옵션(최대 인원, 턴 시간) | `renderWaitingShell` |
| 게임 | 가운데에 **풍선**(누를수록 커진다, 터지는 범위의 최대값에 가까울수록 크고 팽팽하게), "지금까지 23번 · 5~24번 사이에서 터져요", 참가자 줄(차례·타이머), 큰 **펌프** 버튼과 **넘기기** 버튼, 이번 차례 점 3개(누른 만큼 채움), 기록(누가 몇 번 눌렀는지) | 360px 한 손 조작. 업다운 화면과 같은 틀. **시안을 먼저 보여 준다** |
| 당첨 | 풍선이 터지는 연출, 당첨자, 터지는 횟수 공개, 다시 하기 / 나가기, 전체 기록 | 파티 게임 공통 결과 화면 (`updown-bomb.md` 9장) |

입력: 펌프 버튼은 내 차례이고 이번 차례에 3번 미만일 때만 켜진다. 넘기기는 1번 이상 눌렀을 때만 켜진다. 빠르게 두 번 눌러도 서버가 순서대로 처리하고, 차례가 넘어간 뒤 도착한 입력은 `STALE_TURN`으로 버린다. 키보드: Space(또는 Enter) = 펌프, → = 넘기기.

연출: 펌프마다 풍선이 조금 커지며 흔들린다 (200ms). 터질 때 조각이 흩어지고 "펑" (0.6초). 동작 줄이기 설정이면 크기만 바뀌고 흔들림·조각은 없다.

## 10. 기록 (DB)

판 요약(ADR 0002, `games.summary`): 인원, 터지는 횟수, 전체 펌프 수, 차례 수(`moveCount`), 대신 누른 차례 수(`autoMoveCount`), 봇 여부. 순위는 파티 게임 공통(당첨자 2위, 나머지 1위). `/stats` 게임별 지표: 평균 차례 수, 시간 초과로 대신 누른 비율.
