# 운영 통계 대시보드 명세서 v1

- 작성일: 2026-11-25
- 상태: 결정 반영 (2026-11-25)
- 주소: **`/stats`** (게임과 같은 사이트). 서버 API: `POST /visit`, `GET /stats?days=7|30|90`

## 1. 개요

하루마다 사이트를 연 사람 수, 판에 참여한 사람 수, 끝난 판 수를 그래프로 본다. 운영자가 사용 추이를 확인하려는 화면이다.

| 항목      | 결정 (2026-11-25)                                                                  |
| --------- | ---------------------------------------------------------------------------------- |
| 볼 수 있는 사람 | 링크를 아는 누구나. 로그인이나 관리자 키는 없다. 숫자 합계만 보여 준다 (ST-07)                 |
| 접속자    | 방문자(사이트를 연 게스트)와 참여자(끝난 판에 들어 있던 게스트)를 함께 그린다       |
| 기간      | 최근 7 / 30 / 90일. 기본 30일                                                       |
| 하루 경계 | 한국 시간 자정                                                                      |
| 봇        | 세지 않는다                                                                         |

## 2. 규칙

| ID    | 규칙         | 상세                                                                                                                                                                                                                     |
| ----- | ------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| ST-01 | 방문자       | 사이트(메인, 로비, 초대 링크)를 연 브라우저가 하루 한 번 게스트 ID를 `POST /visit`로 보낸다. 서버는 게스트 ID를 해시해서 `daily_visitors(day, guest_hash)`에 한 줄만 남긴다. `/stats`만 연 것은 세지 않는다. 이 기능 배포 전 날짜는 0이다 |
| ST-02 | 참여자, 판 수 | 이미 저장하는 `games`(끝난 판)와 `game_players`에서 센다. 참여자는 그날 끝난 판에 있던 서로 다른 게스트 수다. 처음부터 봇인 자리는 세지 않고, 판 중간에 나가 봇으로 바뀐 사람은 센다. 판 수는 게임별로 나눈다. 판이 끝난 시각의 날짜로 센다 |
| ST-03 | 기간         | `days`는 7, 30, 90만 받는다. 다른 값은 30으로 본다. 응답은 오늘을 포함해 오래된 날부터 `days`개이고, 기록이 없는 날은 0이다                                                                                               |
| ST-04 | 날짜         | 모든 날짜는 한국 시간(UTC+9, 서머타임 없음) 기준 `YYYY-MM-DD`다                                                                                                                                                          |
| ST-05 | 쓰기 제한    | 서버는 같은 날 같은 게스트를 메모리에 기억해 DB에 다시 쓰지 않는다. 새 방문 기록은 1초에 50개까지만 쓰고 넘치면 버린다. 형식이 틀린 게스트 ID는 400 (`INVALID_GUEST`) |
| ST-06 | 읽기 부담    | 같은 기간 응답은 1분 동안 다시 집계하지 않는다. 집계가 실패하면 503 (`STATS_UNAVAILABLE`)이고 그 실패는 재사용하지 않는다                                                                                                |
| ST-07 | 공개 범위    | 응답에는 날짜별 숫자 합계만 있다. 닉네임, 게스트 ID, 방 코드는 넣지 않는다                                                                                                                                                |

## 3. 화면

- 위: 기간 선택(7일 / 30일 / 90일), 오늘 방문자·참여자·판 수, 기간 판 수
- **일일 접속자**: 방문자와 참여자 선 그래프. 범례에 기간 평균
- **일일 판 수**: 게임별로 쌓은 막대 그래프. 범례에 기간 합계
- 그래프를 누르거나 마우스를 올리면 그날 숫자를 그래프 위 한 줄에 보여 준다. 기본은 오늘
- 그래프마다 "표로 보기"로 같은 숫자를 표로 본다 (화면 읽기 프로그램용 포함)
- 화면 폭에 맞춰 그래프를 다시 그린다 (360px에서 가로 스크롤 없음)

## 4. 저장

- `003_daily_visitors` 마이그레이션: `daily_visitors (day date, guest_hash text, PRIMARY KEY (day, guest_hash))`
- 게스트 ID 원문은 남기지 않는다 (SHA-256 앞 32자)
- DB가 없는 개발·E2E 환경에서는 메모리에 센다 (서버를 다시 켜면 사라진다)

## 5. 나중에 정할 것

- 관리자만 보게 하기: 서버 환경 변수로 관리자 키를 두고 `/stats` 요청에 붙이는 방식이 가장 간단하다. 필요해지면 따로 정한다
- 오래된 `daily_visitors` 정리 (하루 수백 줄 규모라 당분간 필요 없음)
