# 난수 분포 검증 보고서 (2026-11-26)

- 기준: TC-15 "10만 회 굴림 분포 집계, 카이제곱 검정에서 균등 분포 기각 안 됨" (Phase 1 M6)
- 대상: 운영과 같은 난수 출처 `cryptoRng` (`crypto.randomInt`, S-03)와 게임이 실제로 쓰는 함수
  - 주사위 `rollDie`: 거짓말쟁이 주사위
  - `rng.int(k)`: 첫 선, 오목 무작위 흑, 숫자야구 선공
  - `shuffle`: 원카드 덱
  - `bulls.randomNumber`: 숫자야구 비밀 숫자
- 도구: `pnpm --filter server rng-check -- --n 100000` (`packages/server/src/scripts/rng-check.ts`)
- 환경: Node v24.14.0, darwin/arm64 (개발 Mac). 운영 이미지에서 돌리는 방법은 4장

## 1. 방법

- 검정마다 카이제곱 적합도 검정을 한다. 가설은 "모든 칸이 같은 확률"이다
- 검정 10개를 한 번에 하므로 전체 유의수준 0.01을 10으로 나눠, 검정 하나당 p ≥ 0.001이면 통과로 본다 (본페로니)
- TC-15 주사위 검정은 따로 놓고 봐도 p ≥ 0.05면 기각되지 않는다

| 검정            | 표본        | 칸  | 무엇을 보나                                 |
| --------------- | ----------- | --- | ------------------------------------------- |
| dice-face       | n           | 6   | 주사위 눈 1~6 (TC-15)                       |
| dice-pair       | n/2 쌍      | 36  | 연달아 굴린 두 눈이 서로 영향을 주지 않는지 |
| pick-2 ~ pick-6 | n           | 2~6 | k명 중 한 명 고르기                         |
| shuffle-top     | n/2 번 섞기 | 54  | 섞은 뒤 맨 위에 오는 카드                   |
| shuffle-place   | n/2 번 섞기 | 54  | 첫 카드가 가는 자리                         |
| bulls-digits    | n/4 개      | 40  | 4자리 비밀 숫자의 자리별 0~9                |

## 2. 결과

### 2-1. n = 100,000 (TC-15 기준)

| 검정                  | χ²    | 자유도 | p         |
| --------------------- | ----- | ------ | --------- |
| **dice-face (TC-15)** | 1.63  | 5      | **0.897** |
| dice-pair             | 28.24 | 35     | 0.784     |
| pick-2                | 2.48  | 1      | 0.115     |
| pick-3                | 0.51  | 2      | 0.777     |
| pick-4                | 3.56  | 3      | 0.313     |
| pick-5                | 2.75  | 4      | 0.600     |
| pick-6                | 4.17  | 5      | 0.525     |
| shuffle-top           | 72.87 | 53     | 0.036     |
| shuffle-place         | 49.97 | 53     | 0.593     |
| bulls-digits          | 31.15 | 39     | 0.810     |

**10개 모두 통과.** TC-15 주사위는 p = 0.897로 균등 분포가 기각되지 않는다.

### 2-2. n = 1,000,000

| 검정          | χ²    | 자유도 | p     |
| ------------- | ----- | ------ | ----- |
| dice-face     | 3.31  | 5      | 0.652 |
| dice-pair     | 25.61 | 35     | 0.877 |
| pick-2        | 3.10  | 1      | 0.078 |
| pick-3        | 1.80  | 2      | 0.407 |
| pick-4        | 4.15  | 3      | 0.246 |
| pick-5        | 4.36  | 4      | 0.360 |
| pick-6        | 3.99  | 5      | 0.551 |
| shuffle-top   | 40.26 | 53     | 0.901 |
| shuffle-place | 48.57 | 53     | 0.647 |
| bulls-digits  | 27.79 | 39     | 0.910 |

표본을 10배로 늘려도 모두 통과한다 (7.2초).

### 2-3. 반복 (n = 100,000 × 20번, p값 200개)

난수가 고르면 p값은 0~1에 고르게 흩어져야 한다.

| 항목                 | 관측                                   | 고르다면 기대값 |
| -------------------- | -------------------------------------- | --------------- |
| 통과한 실행          | 20 / 20                                | —               |
| p < 0.05             | 6                                      | 10              |
| p < 0.01             | 1                                      | 2               |
| p값 10등분 칸별 개수 | 17, 20, 22, 20, 20, 19, 23, 20, 23, 16 | 칸마다 20       |
| 주사위 p값 범위      | 0.100 ~ 0.994                          | —               |

p값이 고르게 흩어져 있어, 특정 함수가 한쪽으로 치우친 흔적이 없다. 2-1의 shuffle-top p = 0.036도 이 정도 흩어짐 안에 있고, 1,000,000번에서는 0.901이다.

## 3. 검정이 실제로 치우침을 잡는지

`test/rng-check.test.ts`에서 "가장 큰 값이 20번에 1번 다시 뽑히는"(6이 약 5% 덜 나오는) 난수를 넣으면, n = 100,000에서 주사위 검정이 기준(0.001) 아래로 떨어져 실패한다. 이 정도 치우침이면 이 도구로 잡힌다.

## 4. 운영 이미지에서 돌리기 (선택) 🙋

운영은 Linux arm64 컨테이너에서 같은 `crypto.randomInt`를 쓴다. 같은 결과인지 확인하려면 VM의 `~/wmg/infra`에서 실행한다. 판에는 영향이 없고 DB도 쓰지 않는다.

```bash
docker compose exec server node dist/scripts/rng-check.js --n 100000
```

## 5. 결론

- TC-15를 통과했다. 운영 난수 출처로 굴린 주사위 10만 회에서 균등 분포가 기각되지 않는다 (χ² = 1.63, p = 0.897)
- 주사위 외에 첫 선 고르기, 원카드 섞기, 숫자야구 비밀 숫자도 모두 고르다
- 연달아 굴린 두 눈 사이에 상관이 보이지 않는다
- 이 검증은 CI에 넣지 않는다. 진짜 난수라 우연히 기준 아래로 떨어질 수 있기 때문이다 (1%). 난수 코드를 바꿀 때 이 명령을 다시 돌린다
